## ✨ Features

- **🔢 Four Arithmetic Operations**: Practice addition (+), subtraction (-), multiplication (×), and division (÷)
- **📊 Multiple Difficulty Levels**: Choose from easy, medium, and hard difficulty settings
- **🏆 Score Tracking**: Track your progress and improve your accuracy over time
- **⚡ Speed Training**: Improve calculation speed with timed challenges
- **🎯 Accuracy Monitoring**: Get feedback on correct and incorrect answers
- **🎨 Intuitive UI**: Clean, user-friendly interface designed for students
- **✨ Smooth Animations**: Engaging animations to enhance user experience
- **📈 Progress Analytics**: View your improvement over time

## 🛠️ Built With

- **Language**: Kotlin
- **Platform**: Android
- **IDE**: Android Studio
- **UI Framework**: Android Views/XML
- **Architecture**: MVVM (Model-View-ViewModel)
- **Database**: Room (for local score storage)

## 🎯 Target Audience

- Primary and secondary school students
- Anyone looking to improve basic math skills
- Teachers seeking educational tools for their students
- Parents wanting to help their children practice math

## 🚀 Getting Started

### Prerequisites

- Android Studio Arctic Fox or later
- Android SDK API level 21 or higher
- Kotlin 1.5.0 or later

### Installation

1. Clone the repository

```bash
git clone https://github.com/Sakin08/Math-Game.git
```

2. Open the project in Android Studio

3. Sync the project with Gradle files

4. Run the app on an emulator or physical device

### Building APK

```bash
./gradlew assembleDebug
```

The APK will be generated in `app/build/outputs/apk/debug/`

## 🎮 How to Play


1. **Choose Operation**: Pick the arithmetic operation you want to practice
2. **Solve Problems**: Answer the math questions as quickly and accurately as possible

3. **Improve**: Use the feedback to identify areas for improvement
